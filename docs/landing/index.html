Watch your agents build.

Mission control for your AI coding agents, rendered as a living city. Every file is a building. Every Claude Code or Codex agent is a drone, flying to the files it edits.

Windows x64 · Installer or portable · MIT licensed

Every agent, in one place.

Skyline reads the session logs your agents already write, and draws what they are doing as you watch.

Click any file. See who touched it.

The Inspector shows the file's path, size, commits and imports, plus every agent that edited or read it and a read-only preview.

  • Explain the file with a local model
  • Show import arcs in and out of the selected building
  • Recent activity, from live or replayed events

Cost and tokens, per agent, as they run.

The agent dock tracks each session and each subagent, nested under the session that spawned it. Costs use a model price table that lives in one readable file.

  • Input, output and cache tokens per agent
  • Replay recent agent activity, or scrub git history from the first commit
  • Dispatch a new agent in its own git worktree

Start from what is already there.

Open any repository, or try the demo city. Skyline finds the recent Claude Code and Codex sessions on this machine that belong to it, so you can start watching right away.

  • Recent repositories, one click away
  • Detected agent sessions listed on the welcome screen
  • Works without an account or a network connection

Share your city.

Press S for a snapshot: a branded PNG of the framed city with a stats card, copied straight to your clipboard. Press Shift+S for a 10-second flyover video of the orbit.

  • Stats card with agents, edits, files and cost for the open repo
  • Paste the PNG into a post, a chat or a pull request
  • Flyover saved as WebM, ready to share

A city that lives after dark.

Every file is a real low-poly model. Windows light up pane by pane, cars move along the streets, and the Director camera (press V) cuts between shots while you watch.

  • Kenney City Kit models (CC0), drawn as instanced meshes
  • Roads, street lamps and live traffic
  • A moon, an aurora and a far skyline beyond the city edge

Your code and transcripts stay on your machine.

Skyline is local-first by design. There is no account, no telemetry and no cloud service.

Reads

Local logs and your repo

Claude Code transcripts in ~/.claude/projects, Codex rollouts in ~/.codex/sessions, and your repository files and git history.

Sends

Nothing

Skyline does not upload your code, prompts or transcripts. The app's window is locked down by a content security policy that allows it to talk only to itself.

Downloads

One optional model

The only network request is the local model download from Hugging Face, about 1.1 GB, and only when you click the button.

Offline

Works without a model

Digests and explanations fall back to a deterministic summary, so everything still works with no model and no connection.
